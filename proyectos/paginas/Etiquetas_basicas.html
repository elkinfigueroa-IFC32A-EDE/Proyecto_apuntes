Etiquetas basicas

  • <title>

    • Define el título que aparece en la pestaña del navegador o en los resultados de los buscadores.

  • <h1> a <h6>

    • Se utiliza para los titulos y/o subtitulos de la pagina web.

  • <p>

    • Se utiliza para los parrafos de una pagina web.

  • <br>

    • Se utiliza para los entre lineados de una pagina web.

  • & nbsp;

    • Se utiliza para hacer espacios en los textos.

Ejemplo:

Este es un h1

Este es un h2

Este es un h3

Este es un h4

Este es un h5
Este es un h6

Hola esta es mi pagina web
Wenas cabros aqui estamos esta es mi pag web.

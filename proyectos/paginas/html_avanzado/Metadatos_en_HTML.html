Metadatos en HTML

  • Los metadatos son información que se coloca dentro del documento HTML para describir características del documento como el autor, la descripción, las palabras clave o las instrucciones para motores de búsqueda y navegadores.
  • Los metadatos se incluyen dentro de la etiqueta <head> del documento HTML, pero no se muestran directamente en la página web. Estos datos ayudan a los navegadores, motores de búsqueda y aplicaciones a comprender mejor el contenido de la página.

Charset (Conjunto de caracteres)

  • Define el conjunto de caracteres utilizado en el documento, como UTF-8, que soporta casi todos los caracteres.

<meta charset="UTF-8">

Viewport (Responsive Design)

  • Ayuda a configurar la visualización de una página web en dispositivos móviles, garantizando que el contenido se adapte correctamente a diferentes tamaños de pantalla.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Descripción de la página

  • Proporciona una breve descripción del contenido de la página. Esta información es utilizada por los motores de búsqueda para mostrar descripciones en los resultados de búsqueda.

<meta name="description" content="Este es un sitio web que ofrece información sobre HTML5.">

Palabras clave (Keywords)

  • Define un conjunto de palabras clave que describen el contenido de la página. Aunque actualmente no es tan utilizado por los motores de búsqueda, puede ser útil para otras aplicaciones.

<meta name="keywords" content="HTML5, desarrollo web, CSS, JavaScript">

Autor de la página

  • Indica el nombre del autor o empresa responsable del contenido de la página web.

<meta name="author" content="Jaume Pericàs">

Instrucciones para Robots de Búsqueda

  • Indica a los motores de búsqueda cómo indexar y rastrear el contenido de la página.

<meta name="robots" content="index, follow">

Open Graph Tags (para redes sociales)

  • Los Open Graph Tags son metadatos utilizados por las redes sociales (como Facebook o Twitter) para mostrar previsualizaciones personalizadas cuando se comparte un enlace.

<meta property="og:title" content="Título de la página">
<meta property="og:description" content="Descripción de la página">
<meta property="og:image" content="imagen.jpg">
<meta property="og:url" content="https://www.ejemplo.com">

Metadatos para aplicaciones móviles

  • Puedes utilizar metadatos para mejorar cómo se ve la página cuando se guarda en la pantalla de inicio de un dispositivo móvil.

<link rel="apple-touch-icon" href="icon.png">

Favicon

  • Aunque no es un <meta>, el favicon es un metadato visual importante que se muestra en la pestaña del navegador.

<link rel="icon" href="favicon.ico" type="image/x-icon">

lang (atributo)

  • El atributo lang se define dentro de la etiqueta <html> para especificar el idioma general de la página, o dentro de cualquier otra etiqueta HTML para marcar un idioma específico dentro de una parte del contenido.

<!DOCTYPE html>
<html lang="es">
    ...
</html>

IMPORTANTE

Buenas Prácticas para el Uso de Metadatos en HTML:

  • Utiliza el conjunto de caracteres UTF-8 para garantizar que todos los caracteres especiales se muestren correctamente en todos los dispositivos y navegadores.

  • Incluye una descripción relevante de la página para ayudar a los motores de búsqueda a comprender mejor el contenido y mejorar tu clasificación.

  • Optimiza para móviles utilizando la etiqueta viewport para asegurar que la página se adapte correctamente a diferentes dispositivos.

  • Incluye Open Graph Tags si quieres que tu página se muestre de manera atractiva cuando se comparta en redes sociales.

  • Utiliza metadatos de robots para controlar cómo quieres que los motores de búsqueda indexen o no indexen tu página.

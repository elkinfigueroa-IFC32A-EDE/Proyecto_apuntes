Etiqueta <div>

  • La etiqueta <div> (abreviatura de "division") se utiliza para crear contenedores de bloque en una página HTML. Es una etiqueta de nivel de bloque, lo que significa que ocupa todo el ancho disponible y empieza en una línea nueva.
  • No tiene significado semántico en sí misma; simplemente agrupa otros elementos, como texto, imágenes u otras etiquetas, y suele ser estilizada con CSS.
  • Es útil para organizar y diseñar diferentes secciones de una página web.

<div>
    <h2>Sección 1</h2>
    <p>Este es un párrafo dentro de un div.</p>
</div>

Sección 1

Este es un párrafo dentro de un div.

IMPORTANTE

Buenas Prácticas:

  • Uno de los errores más comunes es el uso excesivo de <div> para cualquier cosa, cuando existen etiquetas semánticas más adecuadas como <header>, <section>, <article>, <footer>, etc.

  • Utiliza <div> para agrupar elementos que forman una unidad lógica o visual dentro de la página, pero siempre que no haya una etiqueta semántica más adecuada.

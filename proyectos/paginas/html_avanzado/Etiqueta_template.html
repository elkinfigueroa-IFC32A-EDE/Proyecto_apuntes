Etiqueta <template>

  • La etiqueta <template> se utiliza para definir fragmentos de HTML reutilizables que no se muestran inmediatamente cuando la página se carga.
  • El contenido dentro de un <template> no se añade al documento hasta que se manipula explícitamente con JavaScript, lo que permite crear plantillas que se pueden clonar e insertar en el DOM de manera dinámica.
  • Este elemento es ideal cuando quieres tener estructuras HTML preparadas que podrás añadir al documento en tiempo real, sin que estas sean renderizadas o visibles inicialmente. Esto proporciona mucha flexibilidad para aplicaciones dinámicas.

<template id="miPlantilla">
    <div class="producto">
      <h2>Nombre del Producto</h2>
      <p>Descripcióndelproducto</p>
    </div>
</template>

IMPORTANTE

Buenas Prácticas:

  • Mantén las plantillas simples y modulares: Organiza tu código dentro de <template> de manera que puedas reutilizar fácilmente estas plantillas en diferentes secciones de la página.

  • Clona plantillas con JavaScript: La etiqueta no renderiza su contenido hasta que la invocas con JavaScript, lo que te da control total sobre cuándo y cómo se debe añadir al DOM.

  • Utiliza plantillas para generar contenido dinámicamente: Es muy útil en aplicaciones donde el contenido debe ser generado o actualizado en tiempo real, como listas, formularios o tarjetas de productos.

  • No incluyas contenido activo dentro del template: Los scripts u otros contenidos interactivos dentro del template no se ejecutarán hasta que el contenido sea añadido al DOM, así que asegúrate de añadir los elementos interactivos una vez esté en el documento.

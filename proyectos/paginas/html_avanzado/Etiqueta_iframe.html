Etiqueta <iframe>

  • <iframe> (inline frame) es una etiqueta HTML que permite insertar una página HTML dentro de otra página web. Es una manera más moderna y segura de incrustar contenido externo, como otras páginas web, vídeos, formularios o mapas, dentro de una página principal.
  • Los iframes se utilizan a menudo para contenidos dinámicos como vídeos de YouTube, Google Maps o integraciones de servicios externos.
  • La etiqueta <iframe> se define dentro del cuerpo del documento y se puede personalizar con atributos como width, height, src y frameborder.

<iframe width="560" height="315" src="https://www.youtube.com/embed/ID_VIDEO"
    frameborder="0" allow="autoplay; encrypted-media" allowfullscreen></iframe>

IMPORTANTE

Buenas Prácticas:

  • Evita el uso excesivo de iframes: El uso excesivo de iframes puede hacer que la página sea más lenta y más difícil de gestionar. Utilízalos solo cuando sea necesario (como para incrustar contenido externo).

  • Utiliza el atributo sandbox por seguridad: Cuando incrustas contenido de otros sitios, utiliza el atributo sandbox para limitar las acciones que el iframe puede realizar dentro de tu sitio web, mejorando la seguridad.

  • Optimiza el alto y el ancho: Ajusta el tamaño del iframe para asegurarte de que el contenido se vea correctamente en todos los tamaños de pantalla, especialmente en dispositivos móviles.

  • Utiliza alternativas cuando sea posible: Cuando solo necesites cargar contenido dinámico que puedes generar tú mismo (como un vídeo o una imagen), considera cargarlo directamente en la página en lugar de utilizar un iframe.

  • Utiliza allowfullscreen para vídeos: Si estás incrustando vídeos, permite que se puedan visualizar en pantalla completa con el atributo allowfullscreen para mejorar la experiencia del usuario.

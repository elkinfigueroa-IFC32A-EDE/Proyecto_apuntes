HTML5 y su evolución

  • HTML5 es una evolución importante respecto a las versiones anteriores de HTML: introduce nuevas etiquetas y funcionalidades que permiten una mejor gestión del contenido multimedia, formularios avanzados y mejoras en la semántica de la página web.

Etiquetas en HTML5

  1. <section>: Se usa para agrupar contenido relacionado dentro de una página.
  2. <article>: Representa un bloque de contenido autónomo, como un artículo de un blog, una noticia o un post que puede existir independientemente del sitio web.
  3. <aside>: Define contenido relacionado con el contenido principal pero no esencial. Normalmente se utiliza para barras laterales, anuncios o información complementaria.
  4. <header> y <footer>: Etiquetas para definir las cabeceras y los pies de página.
  5. <nav>: Específica para las barras de navegación del sitio web.
  6. <figure> y <figcaption>: Agrupa elementos multimedia (como imágenes o vídeos) y sus descripciones.

<!DOCTYPE html>
<html lang="es">
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>Página Web Con HTML5</title>
    </head>
    <body>
        <header>
            <h1>Bienvenidos a mi sitio web</h1>
            <nav>
                <ul>
                    <li><a href="#inicio">Inicio</a></li>
                    <li><a href="#sobre">Sobre Nosotros</a></li>
                    <li><a href="#contacto">Contacto</a></li>
                </ul>
            </nav>
        </header>
        <section>
            <h2>Sobre Nosotros</h2>
            <p>Somos una empresa dedicada al desarrollo web y servicios digitales.</p>
        </section>
        <article>
            <h2>Proyecto destacado</h2>
            <p>Desarrollamos una aplicación web para una gran empresa con las últimas tecnologías.</p>
        </article>
        <aside>
            <h3>Noticias Recientes</h3>
            <p>Explora las últimas novedades de nuestro blog.</p>
        </aside>
        <footer>
            <p>&copy; 2024 Empresa XYZ. Todos los derechos reservados.</p>
            <nav>
                <ul>
                    <li><a href="#politica-privacidad">Política de Privacidad</a></li>
                    <li><a href="#aviso-legal">Aviso Legal</a></li>
                </ul>
            </nav>
        </footer>
    </body>
</html>

IMPORTANTE

Buenas Prácticas para Utilizar los Elementos de Estructura:

  • Utiliza elementos semánticos para organizar mejor la página. Esto la hace más comprensible para los navegadores, buscadores y lectores de pantalla.

  • Evita el uso excesivo de divs ("divitis") y aprovecha etiquetas como <section>, <article> y <aside> para que la página sea más semántica.

  • Proporciona enlaces de navegación claros dentro de los elementos <header> y <footer> para mejorar la experiencia de usuario y la accesibilidad.

  • No abuses de <aside>, ya que este elemento debe contener información complementaria y no esencial para el contenido principal.

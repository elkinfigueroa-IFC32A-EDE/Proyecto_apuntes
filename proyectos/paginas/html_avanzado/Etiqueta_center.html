Etiqueta <center>

  • La etiqueta <center> se utilizaba en versiones antiguas de HTML para centrar el contenido dentro de una página web, tanto texto como imágenes u otros elementos.
  • Está obsoleta en HTML5 y se debería evitar su uso. En lugar de <center>, hoy en día se utiliza CSS para centrar los elementos de manera más eficiente.

<center>
    <h1>Bienvenidos a mi sitio web</h1>
</center>

IMPORTANTE

Está obsoleta, no usar.

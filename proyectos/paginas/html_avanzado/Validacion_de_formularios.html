Validación de Formularios

  • HTML5 introduce una serie de nuevos atributos y tipos de entrada para validar los formularios de manera nativa, sin la necesidad de JavaScript.

Atributo required:

  • Marca un campo como obligatorio.

<input type="text" name="nombre" required placeholder="Escribe tu nombre">

Atributo pattern:

  • Permite definir un patrón con expresiones regulares para validar la entrada del usuario.

<input type="text" name="telefono" pattern="\d{9}" placeholder="Escribe tu teléfono">

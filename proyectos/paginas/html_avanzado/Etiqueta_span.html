Etiqueta <span>

  • La etiqueta <span> es una etiqueta inline (en línea) que sirve para estilizar o manipular pequeñas porciones de texto o contenido dentro de una página. A diferencia de <div>, no ocupa todo el ancho disponible, sino solo el espacio necesario.
  • También es una etiqueta no semántica, usada principalmente para aplicar estilos o funcionalidad a un grupo específico de elementos dentro de un texto.

<p>Este es un
<span style="color: red;">texto en rojo</span>.
</p>

Este es un texto en rojo.

IMPORTANTE

Buenas Prácticas:

  • Uso adecuado de <span> para estilizar texto en línea.

  • Evita el uso excesivo de <span>.

  • Combina <span> con CSS para mantener el código limpio.

  • Solo para elementos en línea.

  • Evita abusar del <span> para crear contenedores sin necesidad.

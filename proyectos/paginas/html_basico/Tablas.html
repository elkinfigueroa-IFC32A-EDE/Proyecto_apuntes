Tablas básicas con HTML

Etiqueta <table>:

  • La etiqueta <table> define la tabla y actúa como el contenedor principal.

Etiqueta <tr> (table row):

  • Define una fila dentro de la tabla.

Etiqueta <td> (table data):

  • Crea una celda dentro de una fila de la tabla (datos de la tabla).

<table>
    <tr>
        <td>María</td>
        <td>25</td>
    </tr>
    <tr>
        <td>Juan</td>
        <td>30</td>
    </tr>
</table>

Atributos de Tabla:

  • border:
    • Añade un borde a la tabla y a las celdas.
  • cellpadding:
    • Define el espacio entre el contenido de la celda y el borde de la celda.
  • cellspacing:
    • Controla el espacio entre las celdas de la tabla.

<table border="1" cellpadding="10" cellspacing="5">
    <tr>
        <td>Nombre</td>
        <td>Edad</td>
    </tr>
    <tr>
        <td>Juan</td>
        <td>30</td>
    </tr>
    <tr>
        <td>María</td>
        <td>25</td>
    </tr>
</table>

Tablas con HTML

Etiqueta <thead> (table head):

  • Define el encabezamiento de la tabla, agrupando las filas de encabezamiento (habitualmente las que contienen <th>).

Etiqueta <tbody> (table body):

  • Agrupa el cuerpo de la tabla, es decir, las filas de datos. Se puede servir para separar los datos del encabezamiento.

Etiqueta <th> (table header):

  • Se utiliza para crear una celda de encabezamiento en una tabla. El texto dentro de <th> aparece en negrita y centrado por defecto.

<table border="1" cellpadding="10" cellspacing="5">
    <thead>
        <tr>
            <th>Producto</th>
            <th>Precio</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Manzana</td>
            <td>1€</td>
        </tr>
        <tr>
            <td>Plátano</td>
            <td>2€</td>
        </tr>
    </tbody>
</table>

IMPORTANTE

Buenas Prácticas:

  • Utiliza <thead> y <tbody> para organizar las tablas, especialmente en tablas más grandes, con el fin de separar claramente el encabezamiento del cuerpo de la tabla.

  • Mantén las tablas simples para datos tabulados y utiliza CSS para el diseño más avanzado de las tablas (colores, tamaño de la fuente, etc.).

Enlaces en HTML

  • La etiqueta <a> se utiliza para crear enlaces (links) a otras páginas web, documentos, secciones dentro de la misma página o cualquier otro recurso.
  • El elemento esencial para los enlaces es el atributo href que define la URL a la cual redirigirá al usuario.
  • El texto entre la etiqueta de apertura y la de cierre es el que los usuarios verán y podrán clicar para ser redirigidos.

Atributos de enlaces

  1. href (hypertext reference):
    • Define la URL de destino del enlace.
    • Puede ser un enlace absoluto (una URL completa) o relativo (camino dentro del mismo dominio).
  2. target:
    • Define dónde se abrirá el enlace: en la misma pestaña, en una nueva pestaña o en un nuevo marco.
    • Los valores más habituales son:
      • _blank: Abre el enlace en una nueva pestaña.
      • _self: Abre el enlace en la misma pestaña (valor predeterminado).

<a href="https://www.google.com">Cerca a Google</a>

<a href="#capitol1">Anar al Capítol 1</a>

<h2 id="capitol1">Capítol 1</h2>

<a href="https://www.exemple.com" target="_blank">Obre en una nova pestanya</a>

IMPORTANTE

Buenas Prácticas:

  • Utiliza enlaces descriptivos en lugar de genéricos como "Clica aquí". Esto mejora la accesibilidad y el SEO.
    • Correcto: "Visita la página de Contacto".
    • Incorrecto: "Clica aquí".
  • Utiliza target="_blank" solo cuando sea realmente necesario, ya que abrir enlaces en nuevas pestañas puede confundir a algunos usuarios.
  • Siempre asegúrate de que los enlaces sean accesibles añadiendo una descripción adecuada para usuarios con lectores de pantalla.

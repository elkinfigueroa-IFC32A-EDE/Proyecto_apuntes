Atributos de HTML

Los atributos en HTML son elementos que añaden información extra a las etiquetas HTML para modificar su comportamiento o la apariencia. Estos atributos siempre se colocan dentro de la etiqueta de apertura y siguen el formato nombre="valor".

<!DOCTYPE html>
<html>
    <head>
       <title>Hola mundo</title>
    </head>
    <body>
       <h1 id="titulo" >Título 1</h1>
       <h2 class="importante" >Título 2</h2>
       <h3 style="color: blue; text-align: center;" >Título 3</h3>
       <h4 title="Información adicional" >Título 4</h4>
       <img src="https://picsum.photos/300/300?random=1" alt="Descripción de la imagen" />
       <a href="https://www.ejemplo.com">Enlace</a>
       <p>Este es un párrafo con información.</p>
       <p>Este texto se dividirá<br>en dos líneas.</p>
       <p>Esta es la frase "12&nbsp;hombres".</p>
    </body>
</html>

Diseño básico con Flexbox

Flexbox es un sistema de diseño en CSS que proporciona una manera muy eficiente de distribuir el espacio entre los elementos y alinearlos dentro de un contenedor, incluso cuando el tamaño de los elementos es desconocido o dinámico. Flexbox es ideal para crear diseños de páginas adaptables, ya que facilita la alineación, distribución y ordenación de los elementos dentro de un contenedor.

  1. El contenedor flex (display: flex)

    2. El punto de partida para utilizar Flexbox es establecer display: flex en el elemento contenedor. Este contenedor se conoce como contenedor flex, y sus elementos hijos se conocen como elementos flex. Una vez activado display: flex, puedes utilizar diversas propiedades para ajustar cómo se distribuyen los elementos dentro del contenedor.

    .contenedor {
        display: flex;
    }

    <div class="contenedor">
        <div>Elemento 1</div>
        <div>Elemento 2</div>
        <div>Elemento 3</div>
    </div>

  2. Dirección del flujo (flex-direction)

    3. Por defecto, los elementos flex se disponen en fila horizontalmente. Puedes cambiar la dirección con la propiedad flex-direction. Los valores más comunes son:

    • row: los elementos se colocan en fila (horizontal) (valor por defecto).
    • row-reverse: los elementos se colocan en fila pero en orden inverso.
    • column: los elementos se colocan en columna (vertical).
    • column-reverse: los elementos se colocan en columna pero en orden inverso.

    .contenedor {
        display: flex;
        flex-direction: column;
    }

  3. Alineación horizontal (justify-content)

    4. La propiedad justify-content controla la alineación de los elementos a lo largo del eje principal (horizontal por defecto). Puedes distribuir los elementos flex de diferentes maneras dentro del contenedor. Los valores más comunes son:

    • flex-start: los elementos se alinean al principio del contenedor.
    • flex-end: los elementos se alinean al final del contenedor.
    • center: los elementos se centran dentro del contenedor.
    • space-between: se distribuyen uniformemente con espacio entre ellos.
    • space-around: los elementos tienen espacio alrededor de cada uno.

    .contenedor {
        display: flex;
        justify-content: center;
    }

  4. Alineación vertical (align-items)

    5. La propiedad align-items controla la alineación de los elementos a lo largo del eje transversal (vertical si la dirección es horizontal). Esta propiedad determina cómo se alinean los elementos flex dentro del contenedor en relación con su altura. Los valores más comunes son:

    • stretch: los elementos se estiran para llenar el contenedor (valor por defecto).
    • flex-start: los elementos se alinean en la parte superior del contenedor.
    • flex-end: los elementos se alinean en la parte inferior del contenedor.
    • center: los elementos se centran verticalmente dentro del contenedor.
    • baseline: los elementos se alinean según su línea base de texto.

    .contenedor {
        display: flex;
        align-items: center;
    }

  5. Control del espacio que ocupa cada elemento (flex-grow)

    6. La propiedad flex-grow especifica cómo crecen los elementos flex dentro del contenedor para ocupar el espacio disponible. A cada elemento se le puede asignar un valor numérico que indica cuánto debe crecer en relación con los demás elementos. Si todos los elementos tienen flex-grow: 1, el espacio disponible se distribuirá de manera uniforme.

    .elemento {
        flex-grow: 2; /* Este elemento crecerá el doble que los demás elementos */
    }

Ejemplo y resumen

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Flexbox Básico</title>
    <style>
        .contenedor {
            display: flex;
            flex-direction: row; /* Coloca los elementos en fila */
            justify-content: space-around; /* Distribuye los elementos con espacio alrededor */
            align-items: center; /* Centra los elementos verticalmente */
            height: 200px;
            background-color: lightgray;
        }

        .elemento {
            background-color: lightblue;
            padding: 20px;
            margin: 5px;
        }

        .elemento-grande {
            flex-grow: 2; /* Este elemento ocupará el doble de espacio que los demás */
        }
    </style>
</head>
<body>
    <div class="contenedor">
        <div class="elemento">Elemento 1</div>
        <div class="elemento elemento-grande">Elemento 2 (Grande)</div>
        <div class="elemento">Elemento 3</div>
    </div>
</body>
</html>

Resumen de las propiedades vistas:

  1. display: flex: activa Flexbox en el contenedor.
  2. flex-direction: define si los elementos se colocan en fila o en columna.
  3. justify-content: alinea los elementos horizontalmente (eje principal).
  4. align-items: alinea los elementos verticalmente (eje transversal).
  5. flex-grow: controla cómo crece cada elemento dentro del contenedor para ocupar espacio.

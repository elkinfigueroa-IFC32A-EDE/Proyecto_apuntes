Dimensiones y cajas en CSS

El CSS utiliza el modelo de caja para representar los elementos de una página web. Cada elemento se considera como una caja rectangular que contiene el contenido, rellenos, márgenes y bordes. Es importante entender este modelo porque controla cómo se distribuyen y se ajustan los elementos dentro de la página.

El modelo de caja se compone de cuatro partes principales

  1. Contenido: el contenido real del elemento, como texto, imágenes u otros elementos.
  2. Relleno (padding): el espacio entre el contenido y el borde.
  3. Borde (border): el límite alrededor del relleno.
  4. Margen (margin): el espacio externo entre el borde y otros elementos.

  1. Propiedades de dimensiones (width y height)

    2. Las propiedades width (anchura) y height (altura) se utilizan para definir el tamaño de un elemento. Estos valores se pueden definir en unidades fijas como píxeles (px) o en unidades relativas como porcentajes (%), que dependen del tamaño de su elemento contenedor.

    div {
        width: 300px; /* Anchura fija de 300 píxeles */
        height: 150px; /* Altura fija de 150 píxeles */
    }
    .container {
        width: 50%; /* Anchura del 50% del elemento contenedor */
        height: auto; /* La altura se ajusta automáticamente */
    }

  2. El modelo de caja en CSS

    3. El modelo de caja establece cómo se calculan las dimensiones de un elemento teniendo en cuenta las propiedades de márgenes, rellenos y bordes. Por defecto, el tamaño de width y height solo afecta al contenido. Para incluir el relleno y el borde dentro de las dimensiones del elemento, se puede utilizar la propiedad box-sizing.

    Propiedad box-sizing

    La propiedad box-sizing controla cómo se calculan las dimensiones totales del elemento. Hay dos opciones principales:

    • content-box (valor por defecto): solo incluye el contenido en las dimensiones, mientras que los bordes y los rellenos se añaden aparte.
    • border-box: incluye el contenido, el relleno y el borde dentro de las dimensiones especificadas.

    div {
        width: 200px;
        padding: 20px;
        border: 5px solid black;
        box-sizing: border-box;
    }

  3. Control del desbordamiento (overflow)

    4. Cuando el contenido de un elemento es más grande que las dimensiones especificadas, el CSS ofrece la propiedad overflow para controlar cómo se muestra el contenido que desborda. Los valores más comunes son:

    • visible: el contenido que desborda se muestra fuera del elemento (valor por defecto).
    • hidden: el contenido que desborda se recorta y no se muestra.
    • scroll: muestra barras de desplazamiento, aunque el contenido no desborde.
    • auto: muestra barras de desplazamiento solo si el contenido desborda.

    div {
        width: 150px;
        height: 100px;
        overflow: scroll;
    }

Ejemplo y resumen

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Dimensiones y Cajas en CSS</title>
    <style>
        .caja {
            width: 300px;
            height: 200px;
            padding: 20px;
            border: 5px solid darkblue;
            margin: 20px;
            box-sizing: border-box;
        }

        .desbordamiento {
            width: 150px;
            height: 100px;
            border: 2px solid red;
            overflow: scroll;
        }
    </style>
</head>
<body>
    <div class="caja">
        Esta es una caja con relleno y borde. Las dimensiones totales se calculan con box-sizing: border-box.
    </div>
    <div class="desbordamiento">
        Este es un ejemplo con desbordamiento. Si el contenido es más grande que el espacio disponible, se mostrarán barras de desplazamiento.
    </div>
</body>
</html>

Resumen de las propiedades vistas:

  1. width y height: definen las dimensiones de un elemento.
  2. box-sizing: controla cómo se calculan las dimensiones totales de un elemento teniendo en cuenta el relleno y el borde.
  3. overflow: controla cómo se maneja el contenido que desborda las dimensiones del elemento.

Colores y fondos en CSS

El CSS proporciona varias propiedades para aplicar colores y fondos a los elementos HTML. Estas propiedades son esenciales para mejorar el aspecto visual y la legibilidad de la página web.

  1. Propiedad color

    2. Se utiliza para cambiar el color del texto dentro de un elemento. Puedes definir los colores de varias maneras:

    • Nombres de colores: utilizar nombres predefinidos como red, blue, green, etc.
    • Colores hexadecimales: utilizar un código hexadecimal que empieza por # seguido de seis caracteres (ejemplo: #FF0000 para rojo).
    • RGB: utilizar valores de rgb() donde cada componente (rojo, verde, azul) se especifica entre 0 y 255.
    • RGBA: igual que rgb(), pero con un cuarto valor para la opacidad (valores entre 0.0 y 1.0).

    p {
        color: blue; /* Utiliza un nombre de color */
    }
    h1 {
        color: #FF5733; /* Utiliza un código hexadecimal */
    }
    span {
        color: rgb(0, 255, 0); /* Utiliza el sistema RGB */
    }
    div {
        color: rgba(0, 0, 255, 0.5); /* Utiliza el sistema RGBA con opacidad */
    }

  2. Propiedad background-color

    3. Se utiliza para establecer el color de fondo de un elemento. Igual que la propiedad color, puedes definir colores utilizando nombres, valores hexadecimales, RGB o RGBA.

    body {
        background-color: lightgray; /* Color de fondo gris claro */
    }
    div {
        background-color: #00FF00; /* Color de fondo verde */
    }

  3. Propiedad background

    4. Es una forma abreviada de especificar varias propiedades de fondo a la vez, como el color, la imagen de fondo, la repetición, la posición, etc.

    div {
        background: lightblue url("fons.jpg") no-repeat center cover;
    }

  4. Propiedad background-image

    5. Esta propiedad permite añadir una imagen como fondo de un elemento. Puedes especificar la ubicación de la imagen con una URL.

    div {
        background-image: url("imatge-de-fons.jpg");
    }

    Si quieres que la imagen se repita o se muestre de otra manera, puedes utilizar otras propiedades complementarias:

    • background-repeat: controla si la imagen de fondo se repite. Los valores pueden ser repeat, no-repeat, repeat-x (horizontalmente) o repeat-y (verticalmente).
    • background-position: define la posición de la imagen de fondo (por ejemplo, center, top, left).
    • background-size: permite ajustar el tamaño de la imagen (por ejemplo, cover o contain para adaptarse al tamaño del elemento).

    div {
        background-image: url("fons.jpg");
        background-repeat: no-repeat;
        background-position: center;
        background-size: cover;
    }

Ejemplo y unidades

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Colores y Fondos en CSS</title>
    <style>
        body {
            background-color: lightgray; /* Color de fondo del cuerpo de la página */
        }

        h1 {
            color: darkblue; /* Color del texto del título */
        }

        p {
            color: #333; /* Color de texto con código hexadecimal */
            background-color: #FFD700; /* Fondo amarillo dorado */
        }

        .fondo-imagen {
            background-image: url("fons.jpg");
            background-repeat: no-repeat;
            background-position: center;
            background-size : cover;
        }
    </style>
</head>
<body>
    <h1>Colores y Fondos en CSS</h1>
    <p>Este es un párrafo con texto de color gris oscuro y fondo amarillo dorado.</p>
    <div class="fondo-imagen" style="height: 200px;">
        Este div tiene una imagen de fondo.
    </div>
</body>
</html>

Resumen de las propiedades vistas:

  1. color:define el color del texto.
  2. background-color:establece el color de fondo de un elemento.
  3. background-image:añade una imagen de fondo a un elemento.
  4. background-repeat:controla la repetición de la imagen de fondo.
  5. background-position:define la posición de la imagen de fondo.
  6. background-size:ajusta el tamaño de la imagen de fondo.
  7. background:propiedad abreviada que combina varias propiedades de fondo.

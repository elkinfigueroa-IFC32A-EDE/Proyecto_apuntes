Márgenes, rellenos y bordes en CSS

Los márgenes (margin), los rellenos (padding) y los bordes (border) forman parte del modelo de caja en CSS, que describe cómo se disponen los elementos en la página. Estas propiedades permiten ajustar el espacio exterior e interior de un elemento, así como definir sus límites visuales con un borde.

  1. Márgenes (margin)

    2. La propiedad margin controla el espacio exterior de un elemento, es decir, el espacio que hay entre un elemento y los demás elementos que lo rodean. Los márgenes se pueden definir de manera individual para cada uno de los cuatro lados del elemento (superior, derecho, inferior, izquierdo) o de manera global para todos los lados a la vez.

    p {
        margin: 10px; /* Aplica un margen de 10 píxeles a todos los lados */
    }
    h1 {
        margin-top: 20px; /* Margen superior de 20 píxeles */
        margin-bottom: 10px; /* Margen inferior de 10 píxeles */
        margin-left: 10px; /* Margen izquierdo de 10 píxeles */
        margin-right: 10px; /* Margen derecho de 10 píxeles */
    }

  2. Rellenos (padding)

    3. La propiedad padding controla el espacio interior de un elemento, es decir, el espacio entre el contenido de un elemento (como texto o imágenes) y sus bordes. Igual que con los márgenes, los rellenos se pueden definir para todos los lados o para cada uno individualmente.

    div {
        padding: 20px; /* Aplica un relleno de 20 píxeles a todos los lados */
    }
    h2 {
        padding-left: 15px; /* Aplica un relleno de 15 píxeles al lado izquierdo */
    }

  3. Bordes (border)

    4. La propiedad border se utiliza para añadir un borde alrededor de un elemento. Esta propiedad tiene varios subatributos:

    • Anchura del borde (border-width): define el grosor del borde.
    • Estilo del borde (border-style): puede ser solid (sólido), dashed (rayado), dotted (punteado), etc.
    • Color del borde (border-color): especifica el color del borde.

    div {
        border: 2px solid black; /* Borde de 2 píxeles, sólido y negro */
    }
    p {
        border: 1px dashed blue; /* Borde de 1 píxel, rayado y azul */
    }

Ejemplo y unidades

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Márgenes, Rellenos y Bordes</title>
    <style>
        .caja {
            margin: 20px; /* Margen de 20 píxeles a todos los lados */
            padding: 15px; /* Relleno de 15 píxeles a todos los lados */
            border: 3px solid red; /* Borde de 3 píxeles, sólido y rojo */
        }

        .titulo {
            margin-top: 30px; /* Margen superior de 30 píxeles */
            padding-bottom: 10px; /* Relleno inferior de 10 píxeles */
            border-bottom: 2px dashed green; /* Borde inferior rayado y verde */
        }
    </style>
</head>
<body>
    <div class="caja">
        <h2 class="titulo">Título con márgenes y bordes</h2>
        <p>Este es un párrafo dentro de una caja con márgenes, rellenos y un borde sólido.</p>
    </div>
</body>
</html>

Unidades comunes:

  1. Píxeles (px):
    • Unidad fija, representa un punto en la pantalla.
    • Ejemplo: margin: 20px;
  2. Ems (em):
    • Unidad relativa al tamaño de la fuente del elemento padre.
    • Ejemplo: padding: 2em; (2 veces el tamaño de la fuente).
  3. Rems (rem):
    • Unidad relativa al tamaño de la fuente del elemento raíz (html).
    • Ejemplo: margin: 1.5rem; (1,5 veces el tamaño de la fuente raíz).
  4. Porcentaje (%):
    • Relativa al ancho o al alto del contenedor padre.
    • Ejemplo: padding: 5%; (5% del ancho del contenedor).
  5. Viewports (vw, vh):
    • Relativa al tamaño de la ventana visible.
    • Ejemplo: margin: 5vw; (5% del ancho del viewport).
  6. Bordes (border-width):
    • Grosores predeterminados: thin, medium, thick o valores como px.
    • Ejemplo: border: thick solid black;

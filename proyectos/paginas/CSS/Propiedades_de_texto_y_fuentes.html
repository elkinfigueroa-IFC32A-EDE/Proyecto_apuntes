Propiedades de texto y fuentes

El CSS permite controlar cómo se muestran los textos dentro de una página web. Con diversas propiedades podemos cambiar la fuente, el color, la alineación, el tamaño del texto y otros aspectos visuales para mejorar la legibilidad y la estética del contenido.

  1. Propiedad de font-family

    2. La propiedad font-family define el tipo de letra (tipografía) que se utilizará para un elemento de texto. Puedes especificar una o más fuentes, y el navegador aplicará la primera que esté disponible en el sistema del usuario.

    p {
        font-family: "Arial", sans-serif;
    }

  2. Propiedad de font-size

    3. La propiedad font-size controla el tamaño de la letra. Los valores se pueden definir en diversas unidades, como píxeles (px), ems (em), puntos (pt) o porcentajes (%).

    h1 {
        font-size: 32px;
    }
    p {
        font-size: 14px;
    }

  3. Propiedad de color

    4. La propiedad color define el color del texto. Se pueden utilizar nombres de colores predefinidos, valores en hexadecimal, o el sistema de colores RGB o RGBA.

    p {
        color: red; /* Con nombre de color */
    }
    h1 {
        color: #00FF00; /* Con código hexadecimal */
    }
    span {
        color: rgb(0, 0, 255); /* Con código RGB */
    }

  4. Propiedad de text-align

    5. La propiedad text-align se utiliza para controlar la alineación del texto dentro de un elemento. Los valores más comunes son left (izquierda), right (derecha), center (centrado) y justify (justificado).

    h1 {
        text-align: center;
    }
    p {
        text-align: justify;
    }

  5. Propiedad de font-weight

    6. La propiedad font-weight controla el grosor de la letra. Los valores comunes son:

    • normal: por defecto.
    • bold: texto en negrita.
    • Números entre 100 y 900, donde 400 es el valor por defecto y 700 representa la negrita.

    p {
        font-weight: bold;
    }

  6. Propiedad font-style

    7. La propiedad font-style controla el estilo de la fuente, es decir, si el texto será normal o en cursiva. Los valores más comunes son:

    • normal: texto normal.
    • italic: texto en cursiva.
    • oblique: texto inclinado.

    span {
        font-style: italic;
    }

Aplicacion de estilos

El CSS se puede aplicar a un documento HTML de tres formas principales: online, incrustado (dentro del HTML) y externo (mediante un archivo CSS separado). Cada una de estas formas tiene sus propósitos y usos.

1. Estilos enlinea (Inline styles)

Los estilos online se aplican directamente a un elemento HTML, utilizando el atributo style dentro de la misma etiqueta de el elemento. Este método es adecuado para aplicar estilos a un solo elemento de forma rápida, pero no es recomendable para páginas grandes, dificultando la mantenibilidad.

<p style="color: red; font-size: 20px;">Aquest és un paràgraf amb estils en línia.</p>

Ventajas:

  1. Aplicación rápida y directa en el elemento.

Inconvenientes:

  1. Dificulta la mantenibilidad en sitios webs grandes porque debería aplicarse el estilo en cada elemento manualmente.
  2. No aprovecha la capacidad de reutilizar los estilos.

2. Estilos incrustados (Embedded styles)

Los estilos incrustados se colocan dentro de la sección <head> de un documento HTML, dentro de una etiqueta <style>. Estos estilos se aplican a todos los elementos HTML de la página actual.

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Estilos incrustados</title>
    <style>
        p {
            color: blue;
            font-size: 18px;
        }
        h1 {
            text-align: center;
        }
    </style>
</head>
<body>
    <h1>Este es un título centrado</h1>
    <p>Este párrafo tendrá texto de color azul y tamaño 18 píxeles.</p>
</body>
</html>

Ventajas:

  1. Más eficiente que los estilos en línea, ya que se pueden aplicar estilos a diversos elementos de una misma página desde un solo lugar.

Inconvenientes:

  1. Solo afecta a la página donde se aplica, no se reutiliza entre varias páginas.
  2. Si la página crece demasiado, puede hacer más difícil la lectura y el mantenimiento.

3. Estilos externos (External stylesheets)

Los estilos externos se almacenan en un archivo CSS separado y se enlazan al documento HTML utilizando la etiqueta <link> dentro de la sección <head>. Este es el método más recomendado para la mayoría de los sitios web, especialmente si constan de múltiples páginas.

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Estilos externos</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>Bienvenidos a mi sitio web</h1>
    <p>Este párrafo tendrá texto verde y tamaño 16 píxeles.</p>
</body>
</html>

p {
    color: green;
    font-size: 16px;
}

h1 {
    text-align: center;
    color: darkblue;
}

Posicionamiento básico en CSS

El CSS ofrece diversas técnicas para controlar la ubicación de los elementos en una página web. La propiedad clave para el posicionamiento es position, que tiene varios valores para definir cómo se posiciona un elemento respecto a su elemento contenedor o al documento.

  1. La propiedad position

    2. La propiedad position permite especificar el método de posicionamiento de un elemento. Los valores más comunes son:

    • static (por defecto): los elementos se posicionan de manera normal, siguiendo el flujo del documento. No se puede ajustar manualmente con coordenadas.
    • relative: se posiciona el elemento respecto a su posición original en el flujo del documento. Se pueden utilizar coordenadas para moverlo ligeramente (arriba, abajo, izquierda o derecha).
    • absolute: el elemento se saca del flujo del documento y se posiciona respecto a su elemento contenedor más cercano que tenga una posición definida. Si no hay ningún contenedor definido, se posiciona respecto a la página.
    • fixed: el elemento se saca del flujo del documento y se posiciona respecto a la ventana del navegador. Se mantiene fijo incluso cuando el usuario se desplaza.
    • sticky: el elemento se comporta como relative hasta que llega a un punto en el desplazamiento de la página, después del cual se comporta como fixed.

  2. Propiedades de posicionamiento (top, right, bottom, left)

    3. Cuando se define la propiedad position como relative, absolute, fixed o sticky, puedes utilizar las propiedades top, right, bottom y left para especificar la distancia del elemento respecto a sus límites.

    Ejemplos:

    • top: 10px; : mover el elemento 10 píxeles hacia abajo desde el límite superior.
    • right: 20px; : mover el elemento 20 píxeles hacia la izquierda desde el límite derecho.

    div {
        position: relative;
        top: 20px; /* Mueve el elemento 20 píxeles hacia abajo desde su posición original */
        left: 30px; /* Mueve el elemento 30 píxeles hacia la derecha */
    }

  3. Posicionamiento absoluto (position: absolute)

    4. Con position: absolute, el elemento se saca completamente del flujo normal del documento y se posiciona respecto a su elemento contenedor más cercano con position: relative, absolute o fixed.

    div {
        position: absolute;
        top: 50px;
        left: 100px;
    }

  4. Posicionamiento fijo (position: fixed)

    5. Los elementos con position: fixed se mantienen en una ubicación fija de la pantalla incluso cuando el usuario se desplaza. Se posicionan respecto a la ventana del navegador.

    div {
        position: fixed;
        top: 0;
        left: 0;
        width: 100px;
        height: 100px;
        background-color: red;
    }

  5. Posicionamiento pegajoso (position: sticky)

    6. Los elementos con position: sticky se comportan como relative hasta que el usuario se desplaza por la página y llega a un punto especificado, después del cual el elemento se comporta como fixed.

    h1 {
        position: sticky;
        top: 10px;
    }

  6. Propiedad z-index

    7. La propiedad z-index se utiliza para controlar el orden de superposición de los elementos posicionados (relative, absolute, fixed o sticky). Los valores más altos de z-index colocan el elemento delante de otros elementos con valores inferiores.

    div {
        position: absolute;
        z-index: 10; /* Este elemento se mostrará delante de los demás con z-index inferior */
    }

Ejemplo y resumen

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Posicionamiento en CSS</title>
    <style>
        .relativo {
            position: relative;
            top: 20px;
            left: 30px;
            background-color: lightblue;
            padding: 10px;
        }

        .absoluto {
            position: absolute;
            top: 50px;
            left: 50px;
            background-color: lightgreen;
            padding: 10px;
        }

        .fijo {
            position: fixed;
            top: 0;
            right: 0;
            background-color: coral;
            padding: 10px;
        }

        .pegajoso {
            position: sticky;
            top: 10px;
            background-color: yellow;
            padding: 10px;
        }
    </style>
</head>
<body>
    <h1 class="pegajoso">Título pegajoso</h1>
    <div class="relativo">Este elemento tiene position: relative.</div>
    <div class="absoluto">Este elemento tiene position: absolute.</div>
    <div class="fijo">Este elemento tiene position: fixed.</div>
</body>
</html>

Resumen de las propiedades vistas:

  1. position: static: posicionamiento por defecto.
  2. position: relative: el elemento se mueve respecto a su posición original.
  3. position: absolute: el elemento se posiciona respecto a su contenedor más cercano.
  4. position: fixed: el elemento se fija respecto a la ventana del navegador.
  5. position: sticky: el elemento se comporta como relative hasta que llega a una posición fijada, donde se mantiene pegado.
  6. z-index: controla el orden de superposición de los elementos.

Media Queries (Introducción)

Las Media Queries son una característica poderosa del CSS que permite adaptar el diseño de una página web en función de las características del dispositivo que la está visualizando, como el tamaño de la pantalla, la resolución o la orientación. Esta técnica es clave para implementar diseños responsivos que ofrecen una experiencia óptima tanto en dispositivos móviles como en tabletas u ordenadores de sobremesa.

  1. ¿Qué son las Media Queries?

    2. Una media query es una condición que se añade al CSS para aplicar reglas de estilo solo cuando se cumplan ciertas características del dispositivo o de la ventana del navegador. El ejemplo más común es aplicar estilos diferentes en función de la anchura de la pantalla.

    @media (condición) {
        /* Estilos que solo se aplicarán si se cumple la condición */
    }

  2. Aplicación básica de Media Queries para pantallas de diferente tamaño

    3. Un uso típico de las media queries es adaptar el diseño a diferentes anchuras de pantalla. Por ejemplo, puedes ajustar los estilos para pantallas grandes y pequeñas.

    /* Estilos para pantallas grandes (por encima de 768px de anchura) */
    @media (min-width: 768px) {
        body {
            background-color: lightblue;
        }
    }

    /* Estilos para pantallas pequeñas (por debajo de 768px de anchura) */
    @media (max-width: 767px) {
        body {
            background-color: lightgreen;
        }
    }

  3. Tipos de condiciones más comunes en las Media Queries

    4. A continuación, veremos algunas de las condiciones más comunes que puedes utilizar dentro de las media queries:

    a) Anchura de la pantalla (min-width y max-width)

    Estas condiciones se utilizan para aplicar estilos cuando la ventana del navegador tiene una anchura mínima (min-width) o máxima (max-width).

    @media (min-width: 600px) {
        /* Estilos para pantallas con una anchura de 600 píxeles o más */
    }

    @media (max-width: 600px) {
        /* Estilos para pantallas con una anchura de hasta 600 píxeles */
    }

    b) Altura de la pantalla (min-height y max-height)

    Estas condiciones funcionan de manera similar a las de anchura, pero se basan en la altura de la ventana.

    @media (min-height: 500px) {
        /* Estilos para pantallas con una altura de 500 píxeles o más */
    }

    c) Orientación de la pantalla (orientation)

    Puedes utilizar la condición orientation para aplicar estilos diferentes si la pantalla está en orientación horizontal (landscape) o vertical (portrait).

    @media (orientation: landscape) {
        /* Estilos para dispositivos en orientación horizontal */
    }

    @media (orientation: portrait) {
        /* Estilos para dispositivos en orientación vertical */
    }

  4. Uso de múltiples condiciones en una Media Query

    5. Puedes combinar varias condiciones en una sola media query mediante las palabras clave and u only para especificar estilos muy concretos.

    @media (min-width: 600px) and (max-width: 1200px) {
        /* Estilos aplicados solo si la pantalla tiene entre 600 y 1200 píxeles de anchura */
    }

Ejemplo y resumen

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Diseño Responsive</title>
    <style>
        body {
            font-family: Arial, sans-serif;
        }

        .contenedor {
            display: flex;
            flex-direction: column;
            padding: 20px;
        }

        .elemento {
            background-color: lightblue;
            padding: 10px;
            margin: 5px;
            text-align: center;
        }

        @media (min-width: 768px) {
            .contenedor {
                flex-direction: row;
            }
            .elemento {
                font-size: 24px;
            }
        }

        @media (max-width: 767px) {
            .elemento {
                font-size: 18px;
            }
        }
    </style>
</head>
<body>
    <div class="contenedor">
        <div class="elemento">Elemento 1</div>
        <div class="elemento">Elemento 2</div>
        <div class="elemento">Elemento 3</div>
    </div>
</body>
</html>

Resumen de las propiedades vistas:

  1. @media: define una media query.
  2. min-width y max-width: aplica estilos según la anchura mínima o máxima de la pantalla.
  3. min-height y max-height: aplica estilos según la altura mínima o máxima de la pantalla.
  4. orientation: aplica estilos según la orientación del dispositivo (vertical u horizontal).
  5. and: combina múltiples condiciones en una media query.

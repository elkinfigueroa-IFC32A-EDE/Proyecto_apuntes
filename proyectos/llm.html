CSS

Introduccion al CSS

Aqui aprenderemos como se diseña los documentos HTML mediante la separación técnica entre la estructura del contenido y su apariencia visual.

Aplicacion de estilos

Explora los métodos formales de integración del código CSS, abarcando la implementación mediante hojas de estilo externas, bloques incrustados y declaraciones en línea.

Sintaxis basica del CSS

Comprende la anatomía estructural de las reglas CSS, abordando el funcionamiento de los selectores, las declaraciones, y la asignación de valores a las propiedades.

Propiedades de texto y fuentes

Gestiona la tipografía y el formato del contenido textual mediante propiedades de renderizado como font-family, font-size, text-align y font-weight.

Margenes,rellenos y bordes

Domina el modelo de caja (Box Model) para estructurar el espaciado de los elementos, configurando los márgenes exteriores (margin), rellenos interiores (padding) y límites visuales (border).

Colores y fondo

Define la paleta visual de la interfaz mediante la aplicación de valores hexadecimales y RGB, gestionando colores sólidos, opacidades y propiedades de imagen de fondo como background-image.

Dimensiones y cajas

Configura el tamaño absoluto y relativo de los contenedores utilizando width y height, y controla el cálculo geométrico del elemento mediante la propiedad box-sizing y el manejo de desbordamientos con overflow.

Posicionamiento basico

Modifica el flujo normal del documento utilizando la propiedad position (en sus modalidades static, relative, absolute, fixed y sticky) y establece el orden del eje Z en la superposición de elementos.

Diseño basico con Flexbox

Implementa el módulo de caja flexible para establecer arquitecturas de diseño eficientes, gestionando la distribución dinámica del espacio y la alineación a través de los ejes principal y transversal.

Media Queries

Introduce la adaptabilidad del diseño (Responsive Web Design) mediante la inyección de reglas condicionales @media que evalúan características del dispositivo cliente, como las dimensiones del viewport.

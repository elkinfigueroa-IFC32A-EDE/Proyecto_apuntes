CSS

Introduccion al CSS

Aqui aprenderemos como se diseña los documentos HTML mediante la separación técnica entre la estructura del contenido y su apariencia visual.

Aplicacion de estilos

Explora los métodos formales de integración del código CSS, abarcando la implementación mediante hojas de estilo externas, bloques incrustados y declaraciones en línea.

Sintaxis basica del CSS

Comprende la anatomía estructural de las reglas CSS, abordando el funcionamiento de los selectores, las declaraciones, y la asignación de valores a las propiedades.

Propiedades de texto y fuentes

Gestiona la tipografía y el formato del contenido textual mediante propiedades de renderizado como font-family, font-size, text-align y font-weight.

Margenes,rellenos y bordes

Domina el modelo de caja (Box Model) para estructurar el espaciado de los elementos, configurando los márgenes exteriores (margin), rellenos interiores (padding) y límites visuales (border).

Colores y fondo

Define la paleta visual de la interfaz mediante la aplicación de valores hexadecimales y RGB, gestionando colores sólidos, opacidades y propiedades de imagen de fondo como background-image.

Dimensiones y cajas

Configura el tamaño absoluto y relativo de los contenedores utilizando width y height, y controla el cálculo geométrico del elemento mediante la propiedad box-sizing y el manejo de desbordamientos con overflow.

Posicionamiento basico

Modifica el flujo normal del documento utilizando la propiedad position (en sus modalidades static, relative, absolute, fixed y sticky) y establece el orden del eje Z en la superposición de elementos.

Diseño basico con Flexbox

Implementa el módulo de caja flexible para establecer arquitecturas de diseño eficientes, gestionando la distribución dinámica del espacio y la alineación a través de los ejes principal y transversal.

Media Queries

Introduce la adaptabilidad del diseño (Responsive Web Design) mediante la inyección de reglas condicionales @media que evalúan características del dispositivo cliente, como las dimensiones del viewport.

CSS Avanzado

CSS Avanzado: Introducción

Comprende por qué el CSS debe evolucionar en proyectos complejos, abordando el diseño adaptable, la organización modular del código, el uso de preprocesadores, la optimización y los frameworks CSS.

Selectores avanzados

Comprende por qué el CSS debe evolucionar en proyectos complejos, abordando el diseño adaptable, la organización modular del código, el uso de preprocesadores, la optimización y los frameworks CSS.

Propiedades avanzadas de fuentes y tipografía

Controla la tipografía web con la regla @font-face y los formatos WOFF y WOFF2, y ajusta el texto mediante propiedades como letter-spacing, line-height, font-weight, font-style y text-transform.

Layouts avanzados con Flexbox y Grid

Construye diseños flexibles y en dos dimensiones combinando Flexbox (flex-shrink, align-self) con CSS Grid (grid-template-columns, grid-column, gap), y decide cuándo conviene utilizar cada uno.

Popover API

Crea contenido emergente de forma nativa y sin JavaScript mediante los atributos popover, popovertarget y popovertargetaction, y aplica estilos al fondo con el pseudoelemento ::backdrop.

Variables CSS (Custom Properties)

Centraliza colores, tamaños y espaciados declarando variables con el prefijo -- dentro de :root, reutilízalas con var() y define valores por defecto para evitar fallos en el diseño.

Animaciones y transiciones

Añade movimiento a la interfaz mediante transiciones con transition y animaciones con @keyframes, controlando su duración, retraso, número de repeticiones y dirección con las propiedades animation.

Diseño atractivo y coherente

Aplica criterios de consistencia visual, navegación clara, legibilidad (contraste, unidades relativas y line-height) y optimización de la carga para lograr páginas atractivas y fáciles de usar.

UI/UX

Diferencia la interfaz de usuario (claridad, jerarquía visual, feedback y microinteracciones) de la experiencia de usuario (flujo, fricciones y adaptabilidad), y valora las pruebas de usabilidad como los tests A/B.

Optimización y rendimiento

Reduce el tiempo de carga del CSS mediante minificación, carga condicional y asíncrona, compresión Gzip o Brotli, Autoprefixer, optimización de fuentes y análisis con Lighthouse y Chrome DevTools.

Herramientas modernas Preprocesadores

Escribe CSS más modular con los preprocesadores Sass (SCSS) y LESS, aprovechando variables, anidación, mixins, herencia, estructuras de control y operaciones, e instálalos y compílalos con npm.

Herramientas modernas Frameworks

Compara Bootstrap 5, basado en componentes predefinidos y un sistema de graella, con Tailwind CSS, basado en clases de utilidad, y conoce sus características principales y sus formas de instalación.
